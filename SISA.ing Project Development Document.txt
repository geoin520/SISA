SISA.ing — 项目开发文档
一、项目概述
1.1 基本信息
项目	内容
域名	SISA.ing
中文名称	安全洞察 · 态势感知
英文名称	Security Insights and Situational Awareness
技术栈	Next.js (App Router) + TypeScript + Tailwind CSS
部署平台	Vercel（自动部署，连接GitHub仓库）
数据更新策略	定时任务（ISR / Cron Job）拉取官方数据源
多语言支持	中英双语，默认中文
1.2 项目定位
SISA.ing 是一个一站式Windows Server安全情报聚合平台。它不是信息的简单堆砌，而是像一个信息安全专家一样，从MSRC、CISA、NVD、CNNVD、CNVD等多源权威数据中自动采集、提炼、关联，为用户提供从预警推送、影响评估到修复验证的全链路安全态势感知。

1.3 核心价值
权威可信：所有数据均来自官方源，提供原始链接

实时聚合：自动采集一周内的最新安全信息

智能提炼：对多源信息进行关联分析和优先级排序

清晰呈现：以安全仪表盘的形态展示态势全貌

三、数据源集成方案
3.1 权威数据源清单
数据源	类型	地址	数据内容

MSRC Security Update Guide	Web / RSS	https://msrc.microsoft.com/update-guide	漏洞详情、KB关联

3.2 MSRC CVRF API 使用说明
Base URL: https://api.msrc.microsoft.com

关键端点:

text
GET /updates                    # 获取所有安全更新列表
GET /updates/{key}              # 按ID/CVE/年份筛选
GET /cvrf/{id}                  # 获取CVRF详细文档
OData查询支持:

$filter — 按字段筛选

$orderby — 排序

$top / $skip — 分页

$count — 返回总数

示例: 获取2026年7月后的更新

text
GET /updates?$filter=currentReleaseDate gt 2026-07-01T00:00:00Z&$orderby=severity desc

3.4 NVD CVE API v2.0 使用说明
Base URL: https://services.nvd.nist.gov/rest/json/cves/2.0

关键参数:

cveId — 单个CVE查询

pubStartDate / pubEndDate — 发布日期范围

cvssV3Severity — 严重级别过滤

keywordSearch — 关键词搜索

示例: 查询一周内的高危漏洞

text
GET /cves/2.0?pubStartDate=2026-07-19T00:00:00.000Z&cvssV3Severity=CRITICAL
3.5 数据聚合策略
采集频率: 每日定时拉取一次（北京时间 08:00 刷新数据，09:00 发送日报）

数据保留策略: 仅保留发布日期在一周内的数据

关联逻辑:

从MSRC获取Windows Server相关CVE列表

从NVD补充CVSS评分、CWE分类

从CISA KEV标记是否已被在野利用

从CNVD/CNNVD补充国内漏洞情报

按CVSS评分、利用状态、影响范围进行综合排序

去重与更新:

以CVE编号为唯一键

相同CVE在不同数据源的信息进行合并（优先级：MSRC > NVD > 其他）

数据更新时保留原始发布时间，仅更新内容

角色	色值（Hex）	应用场景

辅助背景	#F0F4F9	页面主背景
卡片背景	#1E2F4D	KPI卡片、数据仪表盘卡片

设计原则:

深色区（#0A1E3C）包裹顶部和底部，浅色区（#F0F4F9）承载主要内容

KPI卡片使用深色背景（#1E2F4D）+ 发光蓝边框（#00A3FF），突出数据

高危信息使用红色（#D13438）警示，一目了然

所有文字与背景对比度不低于 WCAG 2.1 AA 标准
